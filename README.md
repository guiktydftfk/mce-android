## 🚀 下载安装

1. GitHub 页面点 **Code → Download ZIP**
2. 解压后，仓库**根目录**的 `MCE-starlight.apk` 即安装包
3. 传到手机点击安装（首次需允许「安装未知应用」）

备用位置：`release/MCE-latest.apk`（自动更新下载用的同一文件）、`release/MCE-starlight-v0.4.8-stable.apk`（正式版归档）。国内网络下载不便时，可用 `version.json` 里的 gh-proxy 地址。

**0.4.8 正式版已发布**：所有用户可在应用内「设置 → 更新」直接升级；历史版本可在 Git 提交历史中找回（仓库只保留当前正式版安装包；灰度测试通道保留，后续 beta 仍可通过「参与灰度测试」接收）。

## 📦 安装与长期可用

- **覆盖安装**：包名固定 `cn.mce.starlight`、签名证书固定（仓库内 `keystore/debug.keystore`），任意历史版本都可直接覆盖升级，数据保留
- **版本只增不减**：`versionCode` 单调递增，旧版可通过应用内更新升到最新
- **稳定版归档**：`release/MCE-starlight-v0.4.8-stable.apk`（与 `MCE-latest.apk` 同内容），根目录 `MCE-starlight.apk` 指向最新包
- **完整性校验**：`release/SHA256SUMS.txt` 记录版本 / 包名 / 签名指纹 / SHA256，可用 `Get-FileHash .\MCE-starlight-v0.4.8-stable.apk -Algorithm SHA256` 核对
- **离线可用**：已打开过的帖子有磁盘缓存，断网仍可阅读
- **更新来源**：`version.json` 的 `apk` 指向 `release/MCE-latest.apk`（多镜像自动回退）

## 🔄 自动更新与灰度测试

- 清单：仓库根目录 `version.json`
  - 正式通道：`versionName` / `versionCode` / `notes` / `apk` / `emergency`
  - 灰度通道：`canary { versionName, versionCode, uids[], notes, apk }`
- 镜像优先级：`gh-proxy` → `fastly.jsdelivr` → `gcore.jsdelivr` → `raw.githubusercontent`，清单请求带时间戳绕过 CDN 缓存
- 灰度规则：仅当 **当前登录 UID 在 `canary.uids` 名单**、`canary.versionCode > 当前版本`、且设置里「参与灰度测试」开启时，才会收到 beta 更新；普通用户不受影响
- **添加灰测用户**：把他的论坛 UID 加进 `version.json` 的 `canary.uids` 并推送即可，无需重新发版（需对方已安装含灰度更新器的版本，即 0.4.7+）
- **灰测一键回滚**：设置 → 更新 →「一键回滚到最新正式版」（二次确认；系统禁止降级时可选卸载重装）
- **紧急推送**：`"emergency": true` 的版本跳过确认直接后台下载并拉起安装器（Android 仍需用户点一次「安装」）
- 暂停：设置内可暂停自动检查 7 / 15 天

## 🧱 项目结构与架构

> 单模块 Android 原生客户端（Kotlin + Jetpack Compose），把 Discuz X3.5 手机模板包装成原生 App。
> 分层：`ui/`（Compose 界面）→ `data/`（网络 + 解析 + 模型）→ `core/`（会话 / 设置 / 本地状态）。正文不用 WebView 渲染，仅外链需要时交给浏览器。

```
app/src/main/java/cn/mce/starlight/
├── MainActivity.kt              # 入口：主题/字体、真实窗口尺寸宽屏判定
├── MceApplication.kt            # Cookie、设置、草稿、消息中心、Coil 初始化

```

关键约定：
- 解析失败/弱网统一走 `UiError` 文案；关键异常写 `DiagLog`
- 列表滚动位置、导航栈、阅读进度均有本地记忆（旋转/返回不丢）
- 主题色、字号、背景等设置持久化在 `SettingsStore`
- 本地敏感数据（Cookie、草稿、已读签名）用 Android Keystore 加密落盘

## 🐞 问题自查

- **自检报告**：设置 → 诊断 → 自检报告（版本 / 设备 / 登录态 / 设置 / 最近抓取页面，一键复制；可填帖子 ID 做图片自检）

- **开发者**：抓取过的页面落盘到应用私有目录，可 `adb shell run-as cn.mce.starlight ls files/` 查看

## ⚠️ 已知限制

- Android 不允许静默安装：应用内更新需用户点一次「安装」
- 门户资讯（`portal.php`）、活动发帖、非图片附件上传尚未实现
- 用户搜索依赖服务端模板；缺失时已内置电脑版模板回退
- 扫一扫（加好友）依赖系统 WebView 的离线 `BarcodeDetector`，极少数机型不支持时可手动输入好友链接 / UID
- 私信已读使用本地已读账本兜底（论坛手机模板本身存在「读完仍返回未读」问题），换设备后以服务端状态为准
- 灰度 beta 仅对名单 UID 可见；版本号低于当前包的 UID 需先升级到含灰度更新器的版本
- 部分机型 emoji 显示可能受系统字体影响（内容本身已正确存储与解析）
