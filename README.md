## 🚀 下载安装

1. GitHub 页面点 **Code → Download ZIP**
2. 解压后，仓库**根目录**的 `MCE-starlight.apk` 即安装包
3. 传到手机点击安装（首次需允许「安装未知应用」）

备用位置：`release/MCE-latest.apk`（自动更新下载用的同一文件）。国内网络下载不便时，可用 `version.json` 里的 gh-proxy 地址。

## 🆕 本次更新 0.4.2

> 本版本聚焦 **易用性 + 数据准确 + 启动/加载速度**：修正私人数据与论坛数据展示问题，补齐常用入口，优化启动与刷新体验。

### ⚡ 性能
- **启动优化**：Cookie 解密 / 首页缓存 / Coil 初始化移到后台预热；抽屉首次打开才合成；启动请求按「登录 → 板块数据 → 签到提醒（未开启跳过）→ 消息刷新 → 后台检查更新」顺序执行
- **板块拉取顺序**：全国交流 → 项目和活动 → 城市板块 → 星光大厅（最后）；组内并发、组间串行
- **更新弹窗延后**：启动后台检查更新，提示延后到「第二次回到首页」或「下次打开软件」
- **刷新更快**：首页「最新」导读 / 我的 / 全板块三路并行，全板块结果缓存 300 秒并在启动 3 秒后后台预热；关闭 HTTP 缓存，网页新帖不再漏
- **首页图片**：按展示尺寸解码 + 关闭淡入，出图更快

### 🐞 修复
- **私信已读后仍显示未读/弹提醒**：刷新与角标统计先套用本地已读账本
- **QQ号 / 微信号显示成「号」**：改为按网页 `ul.user_box` 结构化字段解析
- **勋章数与实际不符 / 未获得勋章被点亮**：已拥有勋章从资料页「荣誉勋章」区块解析，未获得按「勋章中心」状态（已领取 / 可领取 / 未获得）显示
- **好友在线状态不显示**：改用「在线好友」页判断
- **今日新增星光归零**：消息重置不再清空星光日快照
- **道具中心「我的道具 / 记录」显示错误**：按价格 / 数量 / 时间严格过滤，不再混入快捷菜单

### ✨ 新增 / 优化
- 菜单栏新增「**打Call**」（签到下方）、「**常用表单汇总**」（任务中心下方）
- 「我的资料」重做：补自定义头衔 / 个人签名 / 邮箱状态 / 活跃概况，移除打招呼/发消息/加好友按钮
- 「我的勋章」重做为**勋章墙**（含未点亮勋章与进度）
- 「我的回复」补全版块与回复时间；「我的」页点「星光值」可看明细（社区值/赞赏值/职务值/活动值/实践值/已使用）
- 搜索关键词同时匹配**标题与正文**；设置新增「缓存占用」显示与一键清理

> 本版本聚焦 **速度 / 资源占用 / 安全**：不改变使用方式，但个人数据加密落盘、内存占用更低、启动与解析更省。

### 🐞 修复

- **「我的」显示用户组却没有用户等级**：资料页头部 `usernames` 区同时有用户组与 `Lv.x`，旧实现只取用户组；
  现在两者分开解析、并列显示（如「S4 有爱星 · Lv.4」）
- **删除草稿没有二次确认**：草稿箱删除前弹确认框，避免误删（误删不可恢复）
- **从帖子返回列表保持位置（修复仍回顶）**：每个导读分类独立持有滚动状态，返回首页时精确回到原位置；只有切换分类/筛选才回顶
- **左对齐/居中/右对齐失效**：点工具栏时输入框失焦会丢光标位置；现在记住光标，选区为空时对当前行/整段生效，并提示「已居中」

### 🐞 修复（安全）

- **关闭应用备份**（`allowBackup=false`）：避免登录 Cookie、草稿等个人信息被云备份 / `adb backup` 带走
- **扫一扫 WebView 加固**：关闭文件/内容访问、地理位置与混合内容；**禁止页面跳转到任何外部地址**
  （防止本地 JS 接口被第三方页面利用）
- **版主管理条（对齐网页端）**：管理员/超版/版主在帖子页会看到「版主操作」横条——删除主题 / 升降 / 置顶 / 直播 / 高亮 / 精华 / 图章 / 关闭 / 移动 / 分类 / 复制 / 合并 / 分割 / 修复 / 警告 / 屏蔽 / 用户标签；点开用 APP 原生页完成操作（普通用户不显示）\n- 核查结论：无硬编码密钥/Token；网络请求全部 HTTPS（`usesCleartextTraffic=false`）；代码中无打印 Cookie/正文的日志

### ⚡ 优化

- **个人信息加密存储**（Android Keystore + AES-256-GCM）：登录 Cookie、草稿正文、私信已读签名、消息基线
  全部以密文写入本地；密钥由系统 Keystore 托管、不可导出，GCM 校验可发现篡改；
  **旧明文数据自动迁移**（后台线程，不阻塞启动），Keystore 不可用的极端设备自动降级不影响使用
- **降低内存占用**：图片内存缓存占比 25% → **18%**、磁盘缓存 100MB → **80MB**；
  新增 `onTrimMemory / onLowMemory` 回收：系统内存告急时自动释放图片、首页列表、缩略图**内存**缓存
  （磁盘缓存保留，界面不会重新闪骨架）
- **启动更快**：Cookie 解密与明文迁移移到后台线程，首帧不再等待存储迁移
- **解析更快**：详情页样式解析热点里每段新建的 `Regex` 提升为常量，长贴/多图帖子解析 CPU 更低

### 🔧 其他

- 单测 96 个全绿；模拟器实测：冷启动 **1380ms**、登录态在加密迁移后正常保留、
  本地 Cookie/草稿文件已变为 `enc1:` 密文、Java/Native 堆约 36MB/29MB

## 📦 安装与长期可用

- **覆盖安装**：包名固定 `cn.mce.starlight`、签名证书固定（仓库内 `keystore/debug.keystore`），
  已安装任意历史版本都可直接覆盖升级，无需卸载，登录态 / 设置 / 草稿会保留
- **版本只增不减**：`versionCode` 单调递增，旧版也可通过应用内更新升到最新
- **稳定版归档**：`release/MCE-starlight-v0.4.1-stable.apk`（与 `MCE-latest.apk` 同内容，文件名固定便于长期保存；
  历史 0.4.0 / 0.3.9 / 0.3.8 归档仍在 `release/`）
- **完整性校验**：`release/SHA256SUMS.txt` 记录版本 / 包名 / 签名指纹 / SHA256，可用
  `Get-FileHash .\MCE-starlight-v0.4.1-stable.apk -Algorithm SHA256` 核对
- **离线可用**：原生客户端，断网时仍可浏览已加载内容与本地草稿，联网后自动恢复
- **更新来源**：`version.json` 的 `apk` 指向 `release/MCE-latest.apk`（镜像自动回退）；紧急版本可免确认自动下载

## 📷 好友码与扫码加好友

- **我的好友码**：「我的」→「我的好友码」。本地生成包含你个人主页链接（`home.php?mod=space&uid=<你的 UID>`）的**标准二维码**，
  微信、系统相机、任意扫码器都能识别；编码器自研（`ui/QrCode.kt`），无第三方依赖、不联网。
- **扫一扫（加好友）**：「我的」→「扫一扫（加好友）」。可从**相册选图**或**拍照**，用系统 WebView 自带的
  `BarcodeDetector` **离线**识别二维码；识别到本站用户主页链接后直接打开对方主页，即可按站点规则加好友。
- 兜底：部分机型 WebView 不支持离线条码识别，此时可**手动粘贴好友链接 / UID** 打开对方主页。
- 隐私：识别全程在本机完成，不上传图片、不请求任何第三方识别服务。

## 🔄 自动更新机制

- 清单：仓库根目录 `version.json`（`versionName` / `versionCode` / `notes` / `apk` / `emergency`）
- 镜像优先级：`gh-proxy` → `fastly.jsdelivr` → `gcore.jsdelivr` → `raw.githubusercontent`（国内实测可达性排序）
- 清单请求带时间戳绕过 CDN 缓存；失败会明确提示，不再误报「已是最新」
- 下载：APK 经 gh-proxy，失败回退直连；完成后拉起系统安装器
- 暂停：设置内可暂停 7 / 15 天
- **紧急推送**：`version.json` 加 `"emergency": true` 后，该版本跳过「是否更新」确认直接后台下载并拉起安装器
  （同一版本只自动处理一次；Android 不允许静默安装，仍需用户点一次「安装」）

## 🧱 项目结构与架构

> 单模块 Android 原生客户端（Kotlin + Jetpack Compose），把 Discuz X3.5 论坛手机模板包装成原生 App。
> 分层：`ui/`（Compose 界面）→ `data/`（网络 + 解析 + 模型）→ `core/`（会话 / 设置 / 本地状态）；
> 不使用 WebView 渲染正文，仅在需要时用浏览器打开外部链接。

### 关键约定

- 入口：`MceApplication` 初始化设置/Cookie/缓存/草稿/消息中心等；`MainActivity → ui/MceApp.kt` 单 Activity + 自建导航栈（`Route` + `push/pop`）
- 网络：统一走 `GenericPageClient`（移动 UA、手动 3xx、逐跳 Cookie）；`FormhashStore` 进程内缓存 formhash；`DiscuzResponse` 统一成功/失败判定，失败带服务端原文（避免"假成功"）
- 解析：`MobileForumParser`（列表）、`ThreadDetailParser`（详情 → `ContentBlock`）；文本样式用 `TextSpan`（ARGB/粗体/斜体/下划线/删除线/em），UI 用 `AnnotatedString` 还原；投票解析为 `PollData`；表格解析为 `ContentBlock.Table`；全程容错，解析异常回退纯文本
- 分页：手机模板是 ajax「加载更多」，无分页链接；`hasNextPage` 按「本页是否满 10 楼」推断，客户端再按 pid 去重识别末页
- 状态：`PagedThreadList` 统一列表分页状态；页面加载统一 `LaunchedEffect(key)`；写操作返回 `Result(ok, message)`，读页面返回 `Loading / Content / Error`
- 线程：所有网络/磁盘 IO 在客户端内部 `withContext(Dispatchers.IO)`；图片统一 Coil（列表缩略图另有本地缓存）

## ⚠️ 已知限制

- 普通应用无法完全静默安装：系统安装器需用户点一次「安装」（Android 安全限制）
- 门户资讯（`portal.php`）、活动发帖、附件（非图片）上传尚未实现（投票发帖与**帖子内投票参与**已支持）
- **用户搜索**（搜用户）在论坛手机模板缺失 `mytpl/menubottom.htm` 时服务端会 503：客户端已内置电脑版模板回退，可正常使用；根治需论坛后台补模板文件
- **扫一扫（加好友）**依赖系统 WebView 的离线 `BarcodeDetector`：极少数机型/WebView 版本不支持该能力时，请用「手动输入好友链接/UID」兜底；识别本身不联网
- **私信已读**：论坛手机模板存在「读完仍返回未读标记」的问题（网页端同样如此），客户端用本地已读账本兜底；换设备/清数据后会以服务端状态为准
- 私信发送、扫一扫识别建议在真机上验收（模拟器无法完整覆盖相机与条码识别）
